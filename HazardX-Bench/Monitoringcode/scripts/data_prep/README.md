# Unified Dataset Directory

Store all datasets under `/root/autodl-tmp/datasetcsc`. The default script paths and the `dataset_path` and `data_list_path` values in the training configurations are aligned with this layout. Model weights and training outputs continue to use their existing paths. Changing these paths does not move or download existing source data; place the datasets as follows.

```text
/root/autodl-tmp/datasetcsc/
├── flood/
│   ├── CAU_Flood/
│   │   ├── raw/{train,test}/{flood_vv,opt,vv}/*.png
│   │   ├── PRE/, POST/, GT/                 # generated by the reorganization script
│   │   └── train.txt, validation.txt, test.txt
│   └── FloodPlanet/
│       ├── CSDAP_complete/<region>/{PS,labels}/*.tif
│       └── train.txt, validation.txt, test.txt
├── landslide/
│   ├── Landslide4Sense/
│   │   ├── TrainData/{img,mask}/*.h5
│   │   ├── ValidData/{img,mask}/*.h5
│   │   ├── TestData/{img,mask}/*.h5
│   │   └── train.txt, val.txt, test.txt       # lists provided with the repository
│   └── LANDREF/
│       └── reference_data/
│           ├── train_n3_s1s2.h5
│           ├── val_n3_s1s2.h5
│           ├── testind_n3_s1s2.h5
│           └── testspt_n3_s1s2.h5             # optional spatial test set
└── wildfire/
    ├── floga/
    │   ├── raw_h5/*.h5
    │   ├── data_split.csv
    │   ├── converted_data_256/                # generated in step 1; contains split PKL files
    │   └── patch256/{T1,T2,GT}/               # generated in step 2; contains split TXT files
    ├── raw/S2-WCD/                            # extracted S2-WCD data
    └── s2_wcd/                                # converted S2-WCD output and split lists
```

Run the following commands from the HazardX project root:

```bash
# CAU-Flood: read the default raw data and generate PRE/POST/GT and split lists
python scripts/data_prep/flood/reorganize_cau_flood.py

# FloodPlanet: create random splits for the default PS data; skip if lists already exist
python scripts/data_prep/flood/prepare_segmentation_splits.py

# LANDREF: train directly from the original HDF5 files; perform format checks only
python scripts/data_prep/landslide/LANDREF/prepare.py \
  --output-dir /root/autodl-tmp/datasetcsc/landslide/LANDREF/checks

# FLOGA: create patches, then organize them according to data_split.csv
python scripts/data_prep/wildfire/floga/create_dataset.py \
  --out_size 256 256 --sample 1 --random_seed 999
python scripts/data_prep/wildfire/floga/data_convert.py --patch_size 256

# S2-WCD: read from wildfire/raw/S2-WCD and write to wildfire/s2_wcd
python scripts/data_prep/wildfire/s2_wcd/data_convert.py --mode all
```

Landslide4Sense requires no format conversion; extract it to the location shown above. The copied split lists use image paths relative to the dataset root. All scripts still accept their original command-line options for overriding default paths. For detailed input formats and split behavior, see the [flood](flood/README.md), [landslide](landslide/README.md), and [wildfire](wildfire/README.md) guides.

FLOGA patch-generation PKL files may contain the file paths used during creation. If an existing `converted_data_256` directory is moved, regenerate its index with `create_dataset.py --stages 2`, using the original patching and split parameters, and then rerun `data_convert.py`. Changing only the training configuration cannot repair paths stored in those PKL files.
