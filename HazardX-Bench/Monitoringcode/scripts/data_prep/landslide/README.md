# Landslide Dataset Preparation

This directory contains preparation guides for **Landslide4Sense** and **LANDREF**. Run all commands from the HazardX project root. Use Python 3.10 or later. The LANDREF validation utility requires `h5py` and `PyYAML`:

```bash
pip install h5py pyyaml
```

## Landslide4Sense

The extracted dataset provides `TrainData`, `ValidData`, and `TestData`. Preserve the original split:

```text
<L4S_ROOT>/
├── TrainData/
│   ├── img/image_*.h5
│   └── mask/mask_*.h5
├── ValidData/
│   ├── img/image_*.h5
│   └── mask/mask_*.h5
└── TestData/
    ├── img/image_*.h5
    └── mask/mask_*.h5
```

The image HDF5 key is `img`, with shape `(H, W, 14)`; the label key is `mask`. Use the provided `Landslide4Sense/{train,val,test}.txt` lists. Each line contains an image path relative to the dataset root. No new random split or HDF5 conversion is required.

Update the three paths in the relevant `configs/landslide/l4s/*.yaml` files. For example:

```yaml
dataset:
  name: l4s
  train:
    dataset_path: /root/autodl-tmp/datasetcsc/landslide/Landslide4Sense
    data_list_path: /root/autodl-tmp/datasetcsc/landslide/Landslide4Sense/train.txt
    split: train
  val:
    dataset_path: /root/autodl-tmp/datasetcsc/landslide/Landslide4Sense
    data_list_path: /root/autodl-tmp/datasetcsc/landslide/Landslide4Sense/val.txt
    split: val
  test:
    dataset_path: /root/autodl-tmp/datasetcsc/landslide/Landslide4Sense
    data_list_path: /root/autodl-tmp/datasetcsc/landslide/Landslide4Sense/test.txt
    split: test
```

Keep the other model-specific settings unchanged. The loader already normalizes the 14 channels, so do not apply an additional normalization step. Update any stale absolute paths in the configuration to match the current project and dataset locations.

## LANDREF

The project reads one multivariate HDF5 file per split directly; no tiling or repartitioning is required. Place the files under one `reference_data` directory:

```text
<LANDREF_ROOT>/
├── train_n3_s1s2.h5
├── val_n3_s1s2.h5
├── testind_n3_s1s2.h5
└── testspt_n3_s1s2.h5    # optional spatial test set
```

Every selected variable and `None_MASK` should have shape `(N, 1, H, W)`. The required variables are determined by `dataset.input` in the training configuration. The default U-Net configuration uses pre- and post-disaster Sentinel-2 bands together with DEM and slope, for 22 channels total. Different models may select different variables; validate against the configuration used for training. `CONST_ZERO` is a virtual zero channel generated by the loader and does not need to exist in the HDF5 files.

Run the preparation check with:

```bash
python scripts/data_prep/landslide/LANDREF/prepare.py \
  --dataset-root /root/autodl-tmp/datasetcsc/landslide/LANDREF/reference_data \
  --config configs/landslide/landref/seg_unet.yaml \
  --output-dir /root/autodl-tmp/datasetcsc/landslide/LANDREF/checks
```

The script checks that the train/val/test files and variables exist, verifies sample counts and spatial shapes, reads the first sample of each variable to catch read errors, and validates the count and uniqueness of `IDs_order`. When `IDs_order` is absent, it uses the same indexing convention as the data loader. Outputs include:

- `train.txt`, `val.txt`, and `test.txt`: sample IDs in HDF5 order, for inspection only.
- `summary.json`: input paths, sample counts, shapes, and selected variables.

These outputs are overwritten on subsequent runs. The script does not modify the source HDF5 files. Checking the first sample is not a complete scan of the dataset. The LANDREF loader does not read these text files; training continues to use the `h5_path` values in the configuration.

To check the spatial test set separately:

```bash
python scripts/data_prep/landslide/LANDREF/prepare.py \
  --dataset-root /root/autodl-tmp/datasetcsc/landslide/LANDREF/reference_data \
  --config configs/landslide/landref/seg_unet.yaml \
  --test-h5 testspt_n3_s1s2.h5 \
  --output-dir /root/autodl-tmp/datasetcsc/landslide/LANDREF/spatial_checks
```

The `--test-h5` option is for validation only and does not modify the training configuration. Before training, set `dataset.train/val/test.dataset_path` in the selected configuration to the actual `<LANDREF_ROOT>` and choose the corresponding `h5_path`: use `testind_n3_s1s2.h5` for the independent test set and `testspt_n3_s1s2.h5` for the spatial test set. The loader scales reflectance, DEM, and slope according to `dataset.input.scales`; do not pre-scale the data again. If the configuration uses `landref_cd`, the utility also validates `pre_features` and `post_features`.

For the unified data layout and preparation order, see the top-level [README](../README.md).
